# Car Hero Website

Vite/React marketing website for Car Hero.

## Commands

- `npm run dev` starts the local Vite server.
- `npm run build` creates a production build.
- `npm run lint` runs ESLint.
- `npm run preview` previews the production build.

## Structure

- `src/presentation` contains pages and UI components.
- `src/application` contains app-level providers and hooks.
- `src/infrastructure` contains API and i18n setup.
- `public` contains files served directly by Vite.
